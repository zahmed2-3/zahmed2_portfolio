# Zak Ahmed — TCSS 490 Portfolio

A static HTML/CSS/JavaScript portfolio for five TCSS 490 artifacts.

## Run locally
Open `index.html` in a browser.

## Deploy
Push these files to the root of a public GitHub repository. In repository Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`, and save. Wait for the published site URL.

## Update cards
Edit the relevant `<article class="card">` in `index.html`: replace its idea with the completed project title, description, reflection, and link. Update `AI_LOG.md` for each change.
